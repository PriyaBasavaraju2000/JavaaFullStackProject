# 🍽️ Online Food Delivery Application

A full-stack **Online Food Delivery System** inspired by platforms like **Swiggy & Zomato**, built using **Java + Spring Boot + MySQL + REST APIs**.

This project provides a complete workflow for browsing restaurants, ordering food, managing carts, and processing orders with a structured backend architecture.

---

## 🚀 Project Overview

This application allows users to:
- Browse restaurants and menus
- Add food items to cart
- Place orders
- Track order status
- Manage user profiles and order history

It also includes an **admin-side structure** for managing restaurants, food items, and orders.

## ⚙️ How It Works

### Step 1: User Registration/Login
User creates an account and logs in securely.

### Step 2: Browse Restaurants
System fetches available restaurants from database.

### Step 3: Select Food Items
User views menu and adds items to cart.

### Step 4: Cart Management
Items can be:
- Added
- Updated (quantity change)
- Removed

### Step 5: Place Order
User confirms order → system generates order entry.

### Step 6: Order Processing
Order is stored and tracked in database.
